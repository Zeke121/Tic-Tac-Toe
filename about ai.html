🧠The Minimax Algorithm

The unbeatable AI opponent in our Tic-Tac-Toe game uses the Minimax algorithm, a decision-making algorithm used in game theory and artificial intelligence.

Minimax is a recursive algorithm that excels at finding the optimal move in zero-sum games (where one player's gain is another's loss), particularly in games with perfect information like Tic-Tac-Toe, Chess, and Go.

// The core minimax function
function minimax(board, depth, isMaximizingPlayer) {
  // Check for terminal states (win/lose/draw)
  if (gameOver || depth == 0) {
    return evaluateBoard(board);
  }

  // Maximizing player's turn (AI)
  if (isMaximizingPlayer) {
    let bestScore = -Infinity;
    for (move of possibleMoves) {
      makeMove(move);
      let score = minimax(board, depth-1, false);
      undoMove(move);
      bestScore = Math.max(score, bestScore);
    }
    return bestScore;
  }

  // Minimizing player's turn (Human)
  else {
    let bestScore = Infinity;
    for (move of possibleMoves) {
      makeMove(move);
      let score = minimax(board, depth-1, true);
      undoMove(move);
      bestScore = Math.min(score, bestScore);
    }
    return bestScore;
  }
}

The algorithm simulates all possible game states to find the optimal move by:

  • Recursively examining all possible moves
  • Building a game tree with all possible outcomes
  • Evaluating terminal positions (win, lose, draw)
  • Backing up values through the tree to determine the best move

📊How It Works in Tic-Tac-Toe

In Tic-Tac-Toe, the minimax algorithm creates a complete game tree exploring all possible moves and countermoves to determine the optimal strategy.

For a 3×3 game board, there are 9! = 362,880 possible game sequences, but many lead to identical positions. After accounting for symmetry and early game endings, there are only 26,830 distinct board positions.

The algorithm assigns values to each board state:

  • +10 for AI win states
  • -10 for human win states
  • 0 for draw states

When it's the AI's turn, it chooses the move with the maximum score (hence "max"). When it's the human player's turn, the algorithm assumes the human will choose the move with the minimum score (hence "min").

We also implement Alpha-Beta Pruning to optimize the algorithm by eliminating branches that cannot possibly influence the final decision, dramatically improving performance.
